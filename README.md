# 틈 · 오늘의 작업 공간

계산기와 실시간 날씨를 담은 개인용 생산성 대시보드입니다.

## 기능

- 키보드를 지원하는 계산기
- Open-Meteo 기반 지역별 실시간 날씨
- 집중·휴식 타이머
- 할 일과 메모 (브라우저의 로컬 저장소에 자동 저장)
- 모바일 반응형 화면

## 사용하기

https://shoman2.github.io/teum-app/

별도 설치 없이 `index.html`을 브라우저로 열어도 됩니다. 날씨와 웹 폰트는 인터넷 연결이 필요합니다. 할 일과 메모는 서버로 전송되지 않으며, 사용하는 브라우저와 사이트 주소별로 저장됩니다.

## 수정 후 배포하기

이 저장소 폴더에서 `index.html`을 수정한 뒤 실행합니다.

```sh
git add index.html
git commit -m "Update app"
git push
```

`main` 브랜치를 푸시하면 GitHub Pages가 사이트를 자동으로 업데이트합니다.
