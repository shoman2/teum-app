# 틈 · 오늘의 작업 공간

**날씨 확인부터 계산, 할 일 정리까지 한 화면에서 할 수 있는 개인용 작업 공간입니다.**

책상 위에 계산기, 메모지, 타이머를 모아 둔 것처럼 사용할 수 있습니다. 프로그램을 설치하거나 회원가입할 필요는 없습니다.

### 바로 사용하기

👉 **[틈 앱 열기](https://shoman2.github.io/teum-app/)**

컴퓨터와 휴대폰의 웹 브라우저에서 열 수 있습니다. 자주 사용한다면 즐겨찾기에 추가해 두세요.

## 무엇을 할 수 있나요?

| 기능 | 사용 방법 |
| --- | --- |
| 날씨 | 지역을 선택하면 현재 기온, 날씨 상태, 오늘의 최고·최저 기온, 습도와 풍속을 볼 수 있습니다. |
| 계산기 | 숫자와 계산 버튼을 누르거나 키보드로 입력합니다. 덧셈·뺄셈·곱셈·나눗셈과 퍼센트 계산을 지원합니다. |
| 집중 타이머 | `25분 집중`을 선택하고 `집중 시작`을 누릅니다. 쉬고 싶을 때는 `5분 휴식` 또는 `15분 휴식`을 선택합니다. |
| 오늘 할 일 | 할 일을 입력하고 `+` 또는 Enter를 누릅니다. 끝낸 일은 체크하고, 필요 없는 일은 `×`로 삭제합니다. |
| 생각 한 조각 | 떠오른 생각이나 메모를 입력합니다. 별도의 저장 버튼 없이 자동으로 저장됩니다. |

### 알아 두면 편한 사용법

- **날씨 지역:** 서울, 부산, 인천, 대구, 대전, 광주, 제주 중에서 선택합니다. 날씨는 15분마다 다시 불러오며, 새로고침 버튼으로 직접 갱신할 수도 있습니다.
- **계산기 단축키:** Enter는 계산 결과, Esc는 초기화, Backspace는 입력한 숫자 한 자리 지우기입니다. 메모나 할 일을 입력하는 동안에는 계산기 단축키가 작동하지 않습니다.
- **퍼센트 계산:** `50`을 입력하고 `%`를 누르면 `0.5`가 됩니다.
- **타이머:** 일시 정지 후 이어서 시작할 수 있습니다. 옆의 원형 화살표를 누르면 선택한 모드의 처음 시간으로 돌아갑니다. 브라우저가 닫혀 있는 동안에는 완료 알림이 울리지 않습니다.

## 할 일과 메모는 어디에 저장되나요?

**사용 중인 기기의 브라우저 안에 저장됩니다.** 이를 브라우저의 **로컬 저장소(localStorage)**라고 합니다.

- 같은 브라우저에서 같은 앱 주소를 다시 열면 저장한 내용을 이어서 볼 수 있습니다.
- 다른 기기나 다른 브라우저로는 자동으로 옮겨지지 않습니다.
- 브라우저의 사이트 데이터를 삭제하면 내용도 지워집니다. 비공개·시크릿 창에서는 창을 닫으면 내용이 사라질 수 있습니다.
- 파일을 직접 열어 사용한 기록과 위 웹사이트에서 사용한 기록은 서로 공유되지 않습니다.
- 할 일과 메모는 GitHub나 별도 서버로 전송되지 않습니다. 다만 같은 브라우저를 쓰는 사람은 볼 수 있으므로 비밀번호 같은 민감한 정보는 적지 마세요.

> 날씨를 확인할 때는 외부 날씨 서비스인 [Open-Meteo](https://open-meteo.com/)에 선택한 도시의 좌표를 보내 정보를 받아옵니다. 웹 글꼴은 Google Fonts에서 불러옵니다.

## 내 컴퓨터에서 직접 열려면

1. 이 저장소 상단의 **Code → Download ZIP**을 누릅니다.
2. 내려받은 ZIP 파일의 압축을 풉니다.
3. 폴더 안의 **`index.html`**을 브라우저로 엽니다.

별도 설치나 실행 명령은 필요 없습니다. 인터넷이 없어도 파일을 열어 계산기와 타이머 등을 사용할 수 있지만, **날씨를 불러오려면 인터넷 연결이 필요합니다.** 웹 글꼴을 불러오지 못하면 기본 글꼴로 표시됩니다.

## 앱을 수정하고 사이트에 반영하려면

이 부분은 앱을 직접 고치고 싶은 분을 위한 안내입니다. 앱을 사용하기만 한다면 건너뛰어도 됩니다.

### 어떤 파일을 고치나요?

| 파일 | 역할 |
| --- | --- |
| `index.html` | 앱의 화면, 색상, 기능이 모두 들어 있는 파일입니다. 앱을 바꾸려면 이 파일을 수정합니다. |
| `README.md` | 지금 읽고 있는 소개·사용 안내입니다. 이 파일을 바꿔도 앱 화면은 바뀌지 않습니다. |
| `.gitignore` | Git에 올리지 않을 파일의 목록입니다. |
| `.nojekyll` | GitHub Pages가 앱 파일을 그대로 게시하도록 하는 설정 파일입니다. |

### 수정 → 기록 → 업로드

이미 GitHub 연결이 끝난 로컬 **`teum-app` 폴더**를 기준으로 설명합니다.

1. 편집기에서 `index.html`을 수정하고 저장합니다.
2. 브라우저로 파일을 열어 잘 작동하는지 확인합니다.
3. 터미널에서 `teum-app` 폴더로 이동한 다음 아래 명령을 한 줄씩 실행합니다.

```sh
# 어떤 파일이 바뀌었는지 확인
git status

# 앱 파일을 다음 기록에 포함
git add index.html

# 변경 내용을 설명과 함께 내 컴퓨터에 기록
git commit -m "앱 화면과 기능 수정"

# 기록을 GitHub에 업로드
git push
```

README만 수정했다면 `git add index.html` 대신 `git add README.md`를 사용합니다. 두 파일을 함께 수정했다면 `git add index.html README.md`를 사용하면 됩니다.

**용어를 정리하면:** `git add`는 기록할 파일 고르기, **커밋(commit)**은 변경 내용을 내 컴퓨터에 기록하기, **푸시(push)**는 그 기록을 GitHub에 올리기입니다. 커밋만으로는 웹사이트가 바뀌지 않습니다.

푸시 후에는 **GitHub Pages**가 `main` 브랜치(기본 작업 줄기)의 파일로 웹사이트를 자동 업데이트합니다. GitHub Pages는 저장소의 HTML 파일을 웹사이트로 공개해 주는 기능입니다. 반영에는 몇 분이 걸릴 수 있습니다.

배포 진행 상태는 **[Actions 페이지](https://github.com/shoman2/teum-app/actions)**에서 확인할 수 있습니다. 가장 최근 배포가 성공하면 앱 주소를 새로고침해 보세요.

> 처음 저장소를 만들 때는 GitHub 명령줄 도구인 **GitHub CLI(`gh`)**로 저장소를 생성했습니다. 지금은 연결이 완료되어 있으므로, 평소 수정할 때마다 저장소를 다시 만들거나 로그인할 필요는 없습니다. 인증이 만료됐다면 `gh auth status`로 확인하고 `gh auth login`으로 다시 로그인할 수 있습니다.

## 자주 묻는 질문

**날씨가 나오지 않아요.**

인터넷 연결을 확인하고 날씨 카드 오른쪽 위 새로고침 버튼을 눌러 보세요. 외부 날씨 서비스가 일시적으로 응답하지 않을 때도 있습니다. 표시된 기준 시각은 한국 시간입니다.

**휴대폰에서 작성한 메모가 컴퓨터에 없어요.**

기기 간 동기화 기능은 없습니다. 메모는 작성한 기기의 브라우저에만 저장됩니다.

**수정하고 푸시했는데 화면이 그대로예요.**

먼저 Actions 페이지에서 배포가 끝났는지 확인하세요. 배포가 성공했다면 웹사이트를 새로고침하세요. 그래도 같다면 강력 새로고침(Windows: Ctrl+Shift+R, Mac: Command+Shift+R)을 해 보세요.

**저장소가 공개되어 있으면 내 메모도 보이나요?**

아니요. 공개되는 것은 GitHub에 올린 앱 소스와 안내 파일입니다. 앱에서 입력한 할 일과 메모는 브라우저에만 저장됩니다.
